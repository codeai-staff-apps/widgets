# widgets

Rebuilds of staff "vibe coded" educational widgets as governed mini-apps:
Vite static builds on the @code-dot-org/component-library design system,
deployed to GitHub Pages, one self-contained app per `apps/<id>` directory,
with a gallery at the site root.

Live site: https://codeai-staff-apps.github.io/widgets/

See AGENTS.md for conventions and how to add an app.
